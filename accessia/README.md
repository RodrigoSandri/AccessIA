
# AccessIA

Aplicação web colaborativa para acessibilidade em estabelecimentos.

O AccessIA tem como objetivo ajudar pessoas com deficiência e idosos a encontrar informações sobre acessibilidade em estabelecimentos, permitindo consultar avaliações, fotografias e contribuições de usuários.

## Tecnologias utilizadas

- Next.js
- React
- TypeScript
- Tailwind CSS
- MySQL
- Vercel Blob

## Executar localmente

Instale as dependências:

```bash
npm install
```

Inicie o servidor de desenvolvimento:

```bash
npm run dev
```

Acesse http://localhost:3000 no navegador.
